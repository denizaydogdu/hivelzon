| If only | keşke | If only I had had the time to find out why. | if only / wish + past perfect: geçmişle ilgili pişmanlık. had had (had + had): ilki yardımcı fiil, ikincisi have'in V3'ü; doğrudur. |

| has been working | -dır çalışıyor | My uncle has been working in mines for thirty years. | Aynı yapı; for + süre (for thirty years), since + başlangıç (since 1964). |
